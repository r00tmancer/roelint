## [0.1.0] - 2026-08-15

### Added

- YAML ROE policy and playbook formats
- IP, CIDR, domain, and wildcard target matching
- Nine pre-flight policy checks
- Text, JSON, and SARIF reporters
- Local PDF, DOCX, TXT, and Markdown ROE document importer
- English and Turkish scope, authorization, tool, and technique extraction
- Source evidence with page, line, excerpt, and confidence
- Draft-policy approval gate that prevents unreviewed imports from being used
- Single-command policy decisions with document citations
- Optional MCP policy server for AI agents
- Reusable GitHub Action
- Docker image and release automation
- Tested Python 3.10–3.13 package
