# Code of Conduct

ROE-Lint is a professional security project. Be respectful, constructive, and specific. Harassment, discrimination, threats, doxxing, and encouragement of unauthorized access are not accepted in issues, pull requests, discussions, or other project spaces.

Security research must use systems you own, reserved example targets, or systems for which you have explicit written authorization. Never publish client data, live credentials, private targets, or weaponized examples in this project.

Project maintainers may edit or remove content and temporarily or permanently restrict participation when behavior threatens people, systems, or the health of the community. Report conduct concerns privately through the maintainer's GitHub profile. Security vulnerabilities should use the process in [SECURITY.md](SECURITY.md).
